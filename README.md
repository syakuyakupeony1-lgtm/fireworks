# 🎆 Fireworks — 花火打ち上げサイト

クリック / タップした場所に花火が打ち上がるWebサイトです。
依存ライブラリなし・単一HTMLファイルで動作します。

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# ローカルサーバーで起動する場合
python3 -m http.server 8000
# → http://localhost:8000
```

## 機能

- **クリック地点に打ち上げ**: クリック / タップした位置でちょうど開花するよう初速を物理計算
- **複数同時打ち上げ**: 連打・マルチタッチで何発でも同時に上がる。自動モードは1〜3発ずつ打ち上げ
- **打ち上げ音「ヒューーー」**: Web Audio APIで合成(下降グライドの笛音 + ビブラート + 風切りノイズ)。玉の飛翔時間と長さが同期
- **開花音「ドンッ」**: 重低音のドン + 破裂ノイズ + 遠雷のような余韻 + パチパチという火花の弾け音。玉の大きさで迫力が変化
- **7種類の花火**: 牡丹(基本) / 菊(尾を引く) / 柳(しだれ) / 環(リング) / ハート / 千輪(二段開花) / 色変化。「おまかせ」でランダム
- **UI**: 花火の種類セレクター / ミュート切替 / 音量スライダー / 自動打ち上げON・OFF(自動はランダムな種類で打ち上げ)
- 音声ファイル不要(すべてWeb Audio APIによるリアルタイム合成)

## 技術メモ

- Canvas 2D + `requestAnimationFrame`。残像は `destination-out` の半透明塗りで表現し、火花は `lighter` 合成で加算発光
- 音はブラウザの自動再生制限のため、最初のクリックで `AudioContext` を解放
- 音割れ防止に `DynamicsCompressor` をリミッターとして使用
